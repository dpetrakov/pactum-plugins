    More than Markdown
    YAML, JSON/JSONC, TOML, environment files, text and CSV/TSV, with readable and source views.
    Your review history in Git
    Shared annotations, replies and personal read receipts live in .bb-docs. Ignored files can use device-local review.
    Flowcharts, precisely
    The optional visualizer handles Mermaid flowchart and graph. Other diagram types stay source code.
    What does the landing save?
    These examples use synthetic documents and people. They run in this browser and do not connect to an agent or a repository. Reset controls return each example to its starting state. The installed plugin stores real review data in your project.
    How does the team stay in sync?
    Team members share the Git repository and its review history. Each reader is identified by Git identity and confirms their own reading. Push and pull carry the comments and events. The plugin does not require a Pactum account or a Pactum cloud backend.
