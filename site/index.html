Get bb

Install the standalone Documents plugin. No other Pactum plugin is required.

bb plugin install git:https://github.com/dpetrakov/pactum-plugins.git@^1.13.0 --plugin document-review --tag-prefix document-review-

Requires bb 0.46+ and Plugin SDK 0.6.49+. Saving review state needs a Git identity. English by default, with optional Russian.
