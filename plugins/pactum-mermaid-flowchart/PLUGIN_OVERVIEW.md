## Review the diagram, not just its code

See additions, edits and removals in Mermaid flowcharts while discussing the document in Pactum Docs. Move nodes and groups into a readable personal layout without changing the file.

## What you get

- Interactive Mermaid flowchart/graph blocks and .mmd/.mermaid files.
- Change marks for nodes, connections and groups, with removed elements shown as ghosts.
- Pointer, touch and keyboard layout controls.
- Element geometry for Documents comments and review markers.
- The same read-only canvas for supported diagrams in agent chat replies.

## Requirements

Requires bb 0.46+, Plugin SDK 0.6.49+ and a separate installation of Documents. No account or external service is required. Other Mermaid diagram types remain source code. Source styling and click handlers are not executed.
