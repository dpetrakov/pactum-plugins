## Review documents with agents

Keep the reviewer in control of an explicit review round. Read changes since your last read state, leave a precise annotation and send its instructions to an agent in a bb thread. Review the answer and linked edits, then accept or reply with another instruction.

## What you get

Markdown and structured/text file views, inline discussions, causal read marks with Undo, original-file downloads and an extensible visualizer contract. Adjacent change groups can be marked read together. English is the default interface language; Russian is optional.

## Your data

Shared review history lives in `.bb-docs` in your Git checkout. Ignored files can be tracked in device-local storage. The plugin has no Pactum account or subscription and does not upload data to a Pactum backend. User-authorized batches use your selected bb agent provider.

## Requirements

bb 0.46 or later, Plugin SDK 0.6.49 or later and Git. Supported regular text files are limited to 8 MiB. Saving review state requires a Git identity. No other Pactum plugin is required; additional diagram visualizers are separate installs and are not bundled in this release.

See the [project documentation](https://github.com/dpetrakov/pactum-plugins#readme).
